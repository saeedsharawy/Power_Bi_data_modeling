
# Power BI Data Modeling Project

## Project Overview
A hands-on Power BI project focused on transforming a complex dataset containing multiple interconnected tables into a structured data model. The project involves identifying fact and dimension tables, designing a Star Schema, establishing table relationships, creating a date table, developing DAX measures, and exploring Row-Level Security (RLS).
This project focuses on transforming a complex dataset containing 23 tables into a structured and reliable Power BI data model.

The project is based on the Power BI Data Modeling Portfolio Project tutorial by Data with Baraa and was completed as a hands-on learning project to strengthen my understanding of data modeling and Power BI.

## Objectives
- Explore and understand the source tables.
- Identify fact tables and dimension tables.
- Build a structured Star Schema.
- Establish appropriate table relationships.
- Create a date table and core DAX measures.
- Implement and test Row-Level Security (RLS).
- Validate the final data model.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)

## Data Model
The model covers business entities and processes including customers, products, sales, inventory, campaigns, and order fulfillment.

The model uses fact and dimension tables to organize business data and support analytical reporting.

## Key Learning Outcomes
- Understanding fact tables versus dimension tables.
- Designing a Star Schema.
- Managing relationships and filter propagation.
- Creating core DAX measures.
- Understanding Row-Level Security.
- Validating a Power BI data model.
